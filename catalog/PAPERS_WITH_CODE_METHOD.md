# Papers with Code Scoring

| Factor | Weight |
|---|---:|
| Technical relevance | 20% |
| Reproducibility | 20% |
| Code health | 15% |
| Journal / venue quality | 10% |
| Total citation impact | 15% |
| Citation velocity (citations/year) | 10% |
| GitHub traction / activity | 10% |

Citation impact is deliberately split into **total citations** and **citations/year**. Raw citations reward established scientific impact; citations/year gives newer papers a fairer chance to surface. Both are logarithmically scaled so citation count cannot dominate the ranking.

Citation data is refreshed from **OpenAlex** and repository-health metrics from **GitHub**.


## V1 coverage

The initial expanded V1 set contains **33 curated paper-code pairs**, spanning:

- GEOPHYSICS
- Geophysical Journal International
- Geophysical Prospecting
- Computers & Geosciences
- Seismological Research Letters
- Geochemistry, Geophysics, Geosystems
- Computer Physics Communications
- SoftwareX
- Seismica
- selected computational inverse-problem research

The list intentionally favors papers with clearly linked public code and reproducible workflows over papers with code that cannot be independently located.
