# PetroTechRadar v1.0 — Launch Notes

PetroTechRadar v1.0 introduces a curated technology radar for open-source and emerging oil & gas, geoscience and subsurface software.

## V1 highlights

- 115 curated repositories
- 33 Papers with Code
- Live GitHub metrics
- Citation-aware Papers with Code ranking
- Top cited papers on the repository landing page
- AI / Agent / MCP radar
- Seismic & Geophysics radar
- Research and Emerging radar
- Weekly automated refresh
- Interactive GitHub Pages dashboards when repository visibility is public
- Contribution and submission workflows

## Scope

Exploration, geophysics, geology, petrophysics, reservoir engineering, drilling, production, subsurface data, OSDU, AI for energy and geothermal.
