# Contributing to PetroTechRadar

Contributions are welcome for repository suggestions, paper-code pairs, corrections, categorization improvements, and methodology feedback.

## Repository submissions

Please provide:
- GitHub repository URL
- Domain/category
- Short description
- Why it is relevant to oil & gas, geoscience or subsurface engineering
- Whether it is Core, Emerging, Research or Reference
- Any known paper/publication associated with it

## Papers with Code submissions

Please provide:
- Paper title
- Journal/venue and year
- DOI or paper URL
- GitHub repository URL
- Brief note on reproducibility
- Whether the repository contains code needed to reproduce the reported results

## Review principles

PetroTechRadar prioritizes technical relevance, practical usefulness, reproducibility, project health, activity and openness. Inclusion is curated and is not guaranteed.

Please avoid duplicate repositories, forks that add no meaningful value, generic chatbots with little domain engineering, and repositories with no substantive code.
